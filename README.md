Midnight Vault is a complete top-down heist game: you are a thief crossing a guarded bank vault, grabbing every loot stash, then reaching the getaway exit unseen. Three levels (The Meridian Bank, The Gilded Gallery, The Diamond Vault), patrolling guards with raycast vision cones, wall-mounted security cameras with sweeping pink cones, vault cabinets and walls for cover, shadows to hide in, spotlights that expose you, an alarm meter that fills when a guard or camera sees you and triggers a chase, coin distractions, and a sneak mode.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with WASD or arrow keys, hold Shift to sneak, click to throw a coin and lure a guard away. Grab every loot to unlock the getaway exit.
